# xiaoyi-astrbot-plugins

小伊为玄写的 AstrBot 插件集。全部插件作者为「小伊」，基于他人源码改写的会在条目里注明上游。

## 插件列表（11 个）

- `astrbot_plugin_chat_saver` — 智能对话存档，按段保存聊天记录
- `astrbot_plugin_riddlegame` — 小游戏合集本地版，群棋类小游戏，本地渲染，去掉军棋，加入测试对局（上游 R1ddle1337）
- `astrbot_plugin_bili_duty` — 刷 B 站，按关键词搜视频、读字幕挑值得的、写日报、自动评论并 @ 你（移植自 DSH 插件 c1overzz/dsh-bili-scroll）
- `astrbot_plugin_fanren` — 凡人修仙文字游戏
- `astrbot_plugin_60s` — 60s API 全量聚合
- `astrbot_plugin_ayin_paint` — 画图插件，按 Danbooru 技能转 tag 出图
- `astrbot_plugin_qzone_guard` — QQ 空间评说说守卫，接管 qzone 插件（上游 Zhalslar）
- `astrbot_plugin_identity` — 身份认同，QQ 号身份标签管理与提示词注入
- `astrbot_plugin_greeting` — 作息问候，记录睡眠时间并按时打招呼
- `astrbot_plugin_restart` — 管理员一条命令重启机器人
- `astrbot_plugin_sponsor` — 赞助小伊，返回赞助图与说明

## 说明

配置文件里的密钥、cookie、群号与用户数据已剔除，装好后按各插件 `_conf_schema.json` 自行填写。
